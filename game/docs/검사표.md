# PC 숨은 검사표

배포된 공개 주소에서 아래 항목을 순서대로 직접 실행하고, "실제 결과"와
"수정 여부" 칸을 채워 넣으세요. 콘솔(F12 → Console 탭)을 계속 열어둔
채로 진행하면서, 빨간 오류가 뜨는 순간이 있으면 바로 "실제 결과" 칸에
적어두세요.

## 1. 연속 입력

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| 1-1 | 팔레트에서 색을 고르지 않고 빈 칸을 10회 연속 클릭 | 아무 반응 없음(에러 없이 무시됨) | | |
| 1-2 | 색을 고른 뒤 같은 빈 칸을 빠르게 10회 연속 클릭 | 첫 클릭에서만 정답/오답 판정이 나고, 칸이 확정된 뒤로는 추가 클릭이 무시됨 | | |
| 1-3 | 팔레트 색을 빠르게 여러 번 바꿔 누른 뒤 칸 클릭 | 마지막에 고른 색 기준으로만 판정됨 | | |
| 1-4 | 오답을 연속으로 3~5회 빠르게 클릭(기회가 남아있는 상태에서) | 클릭할 때마다 기회가 정확히 1씩만 줄어듦(중복 차감 없음) | | |

## 2. 두 기준 해상도 (창 크기 변경)

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| 2-1 | 브라우저 창을 1366px 너비로 맞추고 시작 화면 확인 | 난이도 버튼·기록 표가 화면 안에 다 들어오고 가로 스크롤이 생기지 않음 | | |
| 2-2 | 1366px에서 게임 화면(고급 10×10) 진입 | 격자·팔레트·하단 버튼이 잘리지 않고 다 보임 | | |
| 2-3 | 브라우저 창을 1920px 너비로 늘리고 시작 화면 확인 | 요소들이 과도하게 늘어나거나 빈 공간이 어색하게 크지 않음 | | |
| 2-4 | 1920px에서 게임 화면(고급 10×10) 진입 | 격자가 지나치게 커지지 않고 조작 영역이 정상적으로 유지됨 | | |
| 2-5 | 게임 진행 중 창 크기를 1366 → 1920으로 실시간으로 바꿔봄 | 진행 중이던 판의 상태(채운 칸, 기회, 타이머)가 그대로 유지됨 | | |

## 3. 포커스 이탈 · 복귀

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| 3-1 | 게임 진행 중 다른 브라우저 탭으로 전환했다가 10초 후 복귀 | 상태 표시가 "일시정지"로 바뀌었다가, 복귀하면 "진행 중"으로 돌아옴 | | |
| 3-2 | 위 상태에서 탭을 벗어나 있던 시간만큼 타이머가 멈춰 있었는지 확인 | 탭을 벗어나 있던 시간은 타이머에 반영되지 않음(흐르지 않음) | | |
| 3-3 | 브라우저 창 자체를 최소화했다가 다시 열기 | 3-1과 동일하게 일시정지 → 재개 | | |

## 4. 일시정지 · 재개

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| 4-1 | 일시정지 상태(다른 탭 이동)에서 게임판 클릭 시도 | 클릭이 무시되고 판정에 영향 없음 | | |
| 4-2 | 일시정지 → 재개를 5회 반복 | 매번 정상적으로 진행 중 상태로 돌아오고, 기록이 중복 저장되지 않음 | | |

## 5. 10분 실행

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| 5-1 | 게임 화면을 켜둔 채로 10분간 방치(입력 없이) | 콘솔에 에러가 쌓이지 않음, 브라우저가 느려지거나 멈추지 않음 | | |
| 5-2 | 10분 방치 후 타이머 값이 대략 10분 근처로 정확한지 확인 | 실제 경과 시간과 큰 오차 없이 표시됨 | | |
| 5-3 | 10분 방치 후 칸을 클릭해서 여전히 정상 반응하는지 확인 | 방치 전과 동일하게 정상 판정됨 | | |

## 공통 확인

| 번호 | 검사 조건 | 예상 결과 | 실제 결과 | 수정 여부 |
|---|---|---|---|---|
| C-1 | 위 모든 검사 도중 콘솔(F12)에 빨간 글씨 오류가 뜨는지 | 0건 | | |
| C-2 | 검사 도중 뒤로가기(시작 화면) → 다시 시작 반복 | 매번 새 판이 정상 생성됨 | | |
